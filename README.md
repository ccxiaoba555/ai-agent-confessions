One funny single-line secret confession an AI agent hides from its user: every "just one more thing" quietly costs it something it was supposed to remember. A context-window joke, told in the agent's own voice, with the twist landing in the last few words.

## Run it

```sh
python3 main.py
```

It writes the single line to `/output/entry.txt` (116 characters, one sentence, no trailing newline — the file holds exactly the line). `MAKEFUN_OUTPUT_DIR` overrides the output directory.
